# Tech Talks Today Event Website

This project generates a single-page website for a 1-day technical event featuring multiple talks, a schedule, and a search functionality. The website is built using standard HTML, CSS, and JavaScript, with a Node.js script to compile the talk data and frontend assets into a single, serverless `index.html` file.

## Features

*   **Event Schedule:** Displays a clear, chronological schedule of all technical talks with their timings.
*   **Talk Details:** Each talk entry includes the title, speaker(s), category keywords, duration, and a description.
*   **Search by Category:** Users can easily search and filter talks based on their categories.
*   **Responsive Design:** The website is designed to be accessible and visually appealing on various screen sizes.
*   **Serverless Output:** The entire website is compiled into a single `index.html` file, making it easy to host and distribute.

## Technologies Used

*   **Frontend:** HTML, CSS, JavaScript
*   **Backend (Build Process):** Node.js

## Project Structure

*   `build.js`: The Node.js script responsible for generating the `index.html` file.
*   `package.json`: Node.js project configuration and scripts.
*   `talks.json`: Stores the data for all the technical talks.
*   `public/`: Contains static assets like CSS and client-side JavaScript.
    *   `public/style.css`: Styles for the website.
    *   `public/script.js`: Client-side JavaScript for search functionality.
*   `views/`: Contains the HTML template.
    *   `views/template.html`: The base HTML structure into which content is injected.
*   `.gitignore`: Specifies intentionally untracked files to ignore.

## Setup and Usage

To set up and view the website locally, follow these steps:

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/pawand2002/Pawan-Dubey-event-talks-app.git
    cd Pawan-Dubey-event-talks-app
    ```

2.  **Install Dependencies:**
    This project uses Node.js for its build script. Make sure you have Node.js installed.
    ```bash
    npm install
    ```

3.  **Generate `index.html`:**
    The `index.html` file, which contains the complete website, is generated by a Node.js script.
    ```bash
    npm run build
    ```
    This command will create an `index.html` file in the root of your project directory.

4.  **Run a Local Web Server:**
    You can use Python's built-in HTTP server to serve the `index.html` file.
    ```bash
    python3 -m http.server
    ```

5.  **Access the Website:**
    Open your web browser and navigate to `http://localhost:8000`.

    You should now see the "Tech Talks Today" event website with the schedule and an interactive search bar.

## Customizing Talks

You can customize the talks by editing the `talks.json` file. Each entry in the JSON array represents a talk and should have the following structure:

```json
{
  "title": "Your Talk Title",
  "speakers": ["Speaker Name 1", "Speaker Name 2"],
  "category": ["Category1", "Category2"],
  "duration": 60, // Duration in minutes
  "description": "A brief description of your talk."
}
```

After modifying `talks.json`, remember to run `npm run build` again to regenerate `index.html` with the updated information.
